# Especificação: Terminal Portfolio Website

## 1. Visão Geral
Criação de uma página pessoal interativa que emula um terminal bash moderno e clean, centralizado na tela.

## 2. Interface (UI/UX)
- **Container:** Janela centralizada com Glassmorphism (opacidade + blur).
- **Header:** Botões estilo macOS (Red, Yellow, Green).
- **Estilo:** Moderno e Minimalista.
- **Fundo:** Background escuro (Slate/Zinc 950).

## 3. Comandos Implementados (Placeholders)
- `help`: Lista comandos disponíveis.
- `about`: Biografia profissional.
- `experience`: Experiências passadas.
- `projects`: Portfólio de projetos.
- `contact`: Redes sociais.
- `clear`: Limpa a tela.

## 4. Tecnologias
- Astro
- Tailwind CSS
- TypeScript
